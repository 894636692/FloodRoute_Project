# 地图数据查询与规划指南

日期：2026-09-21。适用分支：`experiment-ui/v1.2`。

## 选择起点和终点

1. 在左侧“选择模式”选择“选择起点”。
2. 点击机动车道路附近。系统在 EPSG:32650 中计算点击点到正式候选机动车道路的距离，把蓝色标记放在道路最近点，并保存用于路由的最近端点节点。
3. 改为“选择终点”，以同样方式设置橙色终点。
4. 两点必须对应不同且有向连通的路由节点，之后“开始规划”才可用。

界面保存点击经纬度、吸附点经纬度、道路节点、道路边和吸附距离。内部编号默认折叠在“选点详细信息”中。正式 Routing 继续使用完整 OSM MultiDiGraph，地图展示简化不改变规划精度。

## 哪些位置不可作为起终点

起终点的可选距离为 100 米。建筑内部、公园、水面、空地或明显远离候选机动车道路的位置若超过阈值，会显示：

> 该位置附近没有可规划道路，请选择道路附近的位置。

拒绝点击不会移动已有起终点、清除旧路线、调用规划器、改变地图中心/缩放或执行 `fitBounds`。后端仍保留 500 米安全上限。

## 查看当前位置数据

选择“查看信息”后可点击任意位置，这一模式不受 100 米道路阈值限制，也不会修改起点、终点或运行规划器。页面在地图下方显示：

- 查询时间、最近气象格网和最近可规划道路距离；
- 近 1 小时累计降雨、数据时间、来源和信息新鲜度；
- 最近正式道路段的高程、坡度、低洼程度和平坦度风险；
- 该道路段缓冲区的建成区、植被和水体比例；
- 当前道路的静态风险、降雨风险、综合风险、不确定性和可信风险。

地形与土地覆盖描述的是最近正式道路段及其缓冲区，不代表点击地块本身。缺失或不能可靠解释的字段显示“暂无可靠数据”，不会用 0 代替未知。

## 降雨量与降雨格网

真实数据当前只具有语义明确的 **前一小时累计降雨**，单位 mm，时间采用 ISO 8601 `+08:00`。因此 UI 只显示“近1小时累计降雨”，没有构造 3 小时、6 小时或 24 小时累计量。

打开“降雨格网”后显示 4,232 个官方 WGS84 格网。颜色按 0、0–10、10–25、25–50、50–100、>100 mm 分级，仅用于地图展示，不宣称为灾害等级。点击格网可查看格网编号、1 小时雨量、数据时间和来源。

格网静态 geometry 由浏览器只加载一次；Streamlit 后续只传 `[grid_id, rain_mm, style_level]`。真实场景读取官方快照，模拟场景读取受控实验的 observed 数据，不读取离线 Ground Truth 评价结果。

## 道路风险图层与解释

打开“道路风险”后，颜色表示“道路内涝风险指数”的低、较低、中等、较高、高五档显示分级。浏览器只加载一次 12 米简化的展示 geometry；后台正式路由仍使用 55,727 条完整候选机动车有向边。

展示资产排除 service 类道路并合并视觉重复的反向线，只用于地图可读性。点击可见风险道路可直接查询该正式道路边的长度、名称（如可靠）、类型、地形、土地覆盖、动态降雨和风险组成。路线 pane 始终位于降雨和风险 pane 之上。

## 为什么真实水位未启用

当前候选水位源缺少可验证发布坐标、明确时间语义和已确认测量基准，故 `water.active=false`，不参与道路风险计算。界面只显示“真实水位数据：未启用”，不会显示或反推厘米水深。

模拟场景中的积涝强度是无物理水深含义的实验指标，也不得解释为实际水位。

## 风险指数和真实水深的区别

系统输出是用于路线间比较的 **道路内涝风险指数**。它组合正式静态道路特征、当前降雨、信息新鲜度和不确定性，不是经过真实积水深度标定的预测，也不构成道路通行安全承诺。预计行程按模型固定速度估算，只用于实验比较。
