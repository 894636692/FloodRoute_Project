# 涝途智避：中文演示指南（v1.1）

仓库根目录激活 Python 环境，运行：

```shell
python scripts/run_demo.py
```

浏览器打开 `http://127.0.0.1:8501`。改端口：`python scripts/run_demo.py --server.port=8502`。
按 Ctrl+C 停止。

1. **打开系统。** 按上面命令启动并打开本地地址。若旧版占用端口，改用 8502。
2. **选择数据场景。** 选择“深圳真实降雨快照”或“受控极端降雨场景”。真实快照验证数据链路；模拟情景不是历史实测。
3. **选择时间。** 时间显示为北京时间。真实场景没有延迟、缺失或噪声控件；模拟场景可调观测延迟，高级设置默认折叠。
4. **地图点击选择起点。** 选择模式设为“选择起点”，点击道路附近。蓝点表示吸附后的可规划道路节点。
5. **地图点击选择终点。** 改为“选择终点”后点击，橙点表示终点。起终点必须吸附到不同节点。可清除选点或交换起终点。
6. **选择路径策略。** “最短路径”作为距离对照，“风险优先”考虑风险，“可信优先”还考虑信息新鲜度和不确定性。
7. **开始规划。** 点击按钮后计算当前观测下的路线。绿色表示路线。不连通时重选道路节点；不会跳过通行限制强行连接。
8. **查看指标。** 查看路径距离、长度加权风险暴露、可信度、信息新鲜度、不确定性、预计行程和重规划状态。详细面板保留最大风险、长度加权第九十五百分位和高风险长度占比。
9. **可选动态回放。** 模拟场景点击“动态回放”，从情景开始依次回放，固定本次地图选择的起终点，使用可信优先策略。中文提示区分候选评估和真正换路。结束后的结果时间显示在地图上方，可能不同于侧栏单次规划时间。
10. **下载路线。** 点击“下载本次路线”，得到世界大地坐标系下的路线文件，包含结果时间、真实/模拟标识、策略、指标和吸附记录。

地图默认使用本地道路轮廓，无须 API Key。在线底图依赖网络；关闭时没有瓦片层，只有浅灰背景、道路、路线和标记。组件首次加载可能还要获取第三方脚本，离线实验模式不等于完全断网安装包。保留瓦片提供方的合法署名。
蓝/橙点是吸附位置。点击超过 500 米、不连通或吸附到同一节点会提示。阈值在配置文件中。
旅行时间以 8 m/s 估算；路线不代表实际涉水通行安全。
