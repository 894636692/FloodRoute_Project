# 涝途智避：中文演示指南（v1.2）

仓库根目录激活 Python 环境，运行：

```shell
python scripts/run_demo.py
```

浏览器打开 `http://127.0.0.1:8501`。改端口：`python scripts/run_demo.py --server.port=8502`。
按 Ctrl+C 停止。

1. **打开系统。** 按上面命令启动并打开本地地址。若旧版占用端口，改用 8502。
2. **选择数据场景。** 选择“深圳真实降雨快照”或“受控极端降雨场景”。真实快照验证数据链路；模拟情景不是历史实测。
3. **选择时间。** 时间显示为北京时间。真实场景没有延迟、缺失或噪声控件；模拟场景可调观测延迟，高级设置默认折叠。
4. **可选数据图层。** “降雨格网”显示当前近1小时累计降雨；“道路风险”显示道路内涝风险指数。静态 geometry 只加载一次，开关不会重建地图。
5. **查询地图数据。** 选择“查看信息”并点击任意位置，查看最近格网降雨、最近正式道路的地形/土地覆盖和当前风险组成。该操作不设置端点，也不运行规划器。
6. **地图点击选择起点。** 选择模式设为“选择起点”，点击道路 100 米范围内。蓝点位于道路最近点；超出范围只显示轻量中文提示，已有状态不变。
7. **地图点击选择终点。** 改为“选择终点”后点击，橙点表示终点。起终点必须对应不同节点。可清除选点或交换起终点。
8. **选择路径策略。** “最短路径”作为距离对照，“风险优先”考虑风险，“可信优先”还考虑信息新鲜度和不确定性。
9. **开始规划。** 点击按钮后计算当前观测下的路线。绿色表示路线。不连通时重选道路节点；不会跳过通行限制强行连接。
10. **查看指标。** 查看路径距离、长度加权风险暴露、可信度、信息新鲜度、不确定性、预计行程和重规划状态。详细面板保留最大风险、长度加权第九十五百分位和高风险长度占比。
11. **可选动态回放。** 模拟场景点击“动态回放”，从情景开始依次回放，固定本次地图选择的起终点，使用可信优先策略。中文提示区分候选评估和真正换路，已开启图层随每一帧更新。
12. **下载路线。** 点击“下载当前路线（GeoJSON）”，得到 WGS84 路线及场景、时间、策略、起终点、路线 ID、指标、Trigger 状态和数据来源；普通导出不含 Ground Truth。

地图默认使用本地道路轮廓，无须 API Key。在线底图依赖网络；关闭时没有瓦片层，只有浅灰背景、道路、路线和标记。组件首次加载可能还要获取第三方脚本，离线实验模式不等于完全断网安装包。保留瓦片提供方的合法署名。
蓝/橙点是道路最近吸附位置，路由使用对应端点节点。选择阈值为 100 米，后端安全上限为 500 米；不连通或同一节点会提示。
旅行时间以 8 m/s 估算；路线不代表实际涉水通行安全。
