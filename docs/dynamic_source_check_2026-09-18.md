## 已确认的官方来源

[深圳市水务局 2026-04-15 的官方答复](https://www.sz.gov.cn/hdjlpt/detail?pid=3403292&via=pc)明确提供以下两个入口：

- [测站基本信息表](https://opendata.sz.gov.cn/data/dataSet/toDataDetails/29200_01400987)，资源编号 `29200/01400987`。
- [市水务局积涝点水位数据](https://opendata.sz.gov.cn/data/dataSet/toDataDetails/29200_01403147)，资源编号 `29200/01403147`。

两份公开详情页均返回 HTTP 200，但网页详情可访问不等于数据已经下载成功。站点基本信息表是否只包含积涝站，仍须查看数据项和站点类型。

## 实际访问结果及阻塞原因

浏览器连接失败，未能进行可视化点击。随后只读取了上述公开 HTML；两页的下载逻辑均检查登录状态和实名认证，未满足时停止下载。没有调用下载接口、提交登录信息、申请账号或调用带 appKey 的接口。

因此当前需要用户在官方平台完成登录及必要的实名认证，再核验文件下载。`blocked` 描述本次获取状态，不能解读成数据不存在、官方不提供数据或历史水位永久不可用。

原始网页字节与 SHA-256 记录保存在本地工作目录 `work/dynamic_source_check/20260918T111617828561+0800/`。这些是网页核验证据，不是测站或水位样本；`data/raw/dynamic/` 中尚未写入真实数据。

## 下一次只做的操作

用户打开“测站基本信息表”，通过页面顶部登录入口自行登录；如平台要求，按页面提示完成实名认证。登录后先查看“数据项”或“数据预览”，提供可见字段或页面提示，供下一步检查。密码、验证码和 appKey 不写入仓库，也不需要发送到聊天。

若认证后仍无文件、无历史日期或返回权限错误，继续记录具体提示；可选择平台公开预览样本，或由用户通过官方需求入口询问历史数据开放条件。两者都需要后续实际核验，不能替代历史水位验收。
